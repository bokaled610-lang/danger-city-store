# Danger City — المرحلة الثامنة

## المضاف
- دمج شعار DG الرسمي.
- شاشة تحميل بالشعار.
- واجهة Ultimate سوداء وبرتقالية.
- سلة مشتريات حقيقية.
- مفضلة.
- بحث ذكي واقتراحات فورية.
- ملف مستخدم مختصر.
- رصيد DC وXP.
- عجلة حظ يومية.
- بطاقات هدايا.
- نقاط ولاء.
- لوحة أفضل اللاعبين.
- إشعارات.
- طلبات متعددة المنتجات.
- دعم ذكي.
- فتح تكت Discord.
- تصميم متجاوب للجوال.

## التشغيل
1. ثبّت Node.js وPostgreSQL.
2. انسخ `.env.example` إلى `.env`.
3. عدّل DATABASE_URL.
4. شغّل:

```bash
npm install
npm run db:init
npm start
```

5. افتح:

```text
http://localhost:3000
```

## ملاحظات
- `DEV_LOGIN_ENABLED=true` للتجربة فقط.
- عند النشر الحقيقي اربط Discord OAuth واجعلها false.
- AI يحتاج مفتاح API من جهة السيرفر.
- رابط تكت Discord يوضع في `.env`.
